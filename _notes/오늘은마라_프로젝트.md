# 오늘은 마라?! 프로젝트

> 마라탕 메뉴 결정 장애를 해결하는 슬롯머신 기반 추천 앱
> 배포 URL: https://5mara.vercel.app

---

## 프로젝트 개요

### 타겟
- 초등학생 ~ 중학생 (10~15세)
- 특히 여학생 감성 타겟

### 핵심 가치
- 친구들과 함께 랜덤 뽑기하는 재미
- 결과 카드를 카톡/인스타로 공유 → 바이럴 유도
- 가게 도착 전 미리 메뉴 결정 → 빠른 주문

### 바이럴 루프
```
뽑기 → 결과 카드 생성 → 친구에게 공유 → 친구가 앱 실행 → 반복
```

## 주문 플로우 (4단계)

```
🍜 면 선택
  ↓
✨ 토핑 선택 (5개 그룹, 다중선택)
  ↓
🥩 단백질 선택
  ↓
```

## 완성된 기능

### 화면 구성
- **홈 화면** — 랜덤뽑기 / 직접고르기 / 나의기록 / 홈화면추가
- **랜덤 공개 화면 (RevealScreen)** — 4단계 순차 공개, 단어 빠르게 섞이다 탁 멈춤
- **직접 선택 화면 (StepScreen)** — 4단계 순서대로 선택
- **결과 화면 (ResultScreen)** — 조합 카드 + 이미지저장 + 친구공유 + 기록저장
- **나의 기록 (MyRecordsScreen)** — 저장된 조합 목록, 삭제 기능

### 주요 기능
- [x] 랜덤 뽑기 — 단계별 두근두근 공개 애니메이션
- [x] 직접 고르기 — 4단계 체크리스트
- [x] 조합 이름 자동 생성 — 재료 조합 기반 (특수 조합 포함)
- [x] 이미지 저장 — 결과 카드 PNG 다운로드
- [x] 친구 공유 — Web Share API (카톡/문자 직접 공유)
- [x] 나의 기록 — localStorage 저장/삭제
- [x] PWA — 홈화면 설치 버튼, 오프라인 대응
- [x] 홈화면 플로우차트 — 주문 순서 시각화

| 더블고기 + 맵기2↑ | 💪 고기 불꽃 풀옵션 |
| 토핑 9개↑ | 👑 풀옵션 마라킹 |

### 일반 조합
`맵기 형용사` + `특징 토핑/단백질` + `세트/콤보/조합/스페셜`

## 메뉴 데이터 (`src/data/menuData.js`)

### 면 (6종)
옥수수면, 중국당면, 분모자, 뉴진면, 라면사리, 도삭면

### 토핑 5개군
| 군 | 항목 |
|---|---|
| 1군 (두부) | 푸주, 건두부, 얼린두부, 두부피 |
| 2군 (버섯) | 팽이, 목이, 백목이, 새송이, 느타리 |
| 3군 (완자/햄) | 비엔나, 스팸, 문어완자, 새우완자, 메추리알 |
| 4군 (떡/기타) | 치즈떡, 고구마떡, 수제비, 분모자(토핑), 감자 |
| 5군 (채소) | 숙주, 청경채, 배추, 고수 |

### 단백질 (4종)
소고기(100g), 양고기(100g), 고기 더블(200g), 추가 안 함

### 맵기 (4단계)
0단계(백탕), 1단계, 2단계, 3단계(매운맛)
