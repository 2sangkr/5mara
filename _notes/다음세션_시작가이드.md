### Phase 1 — 허브 런칭 (1~2개월)

#### 기술 스택
- Next.js App Router (단일 레포, 앱별 라우팅: `/mara`, `/lunch`, `/movie`)
- 오늘은 마라 앱 이전
- Vercel 배포

#### 초기 앱 3종
| 앱 | 컨셉 | 비고 |
|---|---|---|
| 🍜 오늘은 마라?! | 이미 있음 | 이전만 하면 됨 |
| 🍽️ 점심 뭐 먹지? | 직장인 점심 룰렛 | 새로 제작 |
| 🎬 뭐 볼까? | OTT 장르 뽑기 | 새로 제작 |

#### 홈 화면 구조
```
[큰 타이틀: 오늘 뭐 하지?]

[카테고리 탭: 먹기 / 보기 / 가기 / 하기]

[앱 카드 그리드]
  🍜 마라탕 뽑기    🍽️ 점심 룰렛
  🎬 뭐 볼까       + 곧 추가 예정...

[오늘의 추천 — 랜덤 앱 하나 띄워주기]
```

#### 작업 순서
```
1주차   Next.js 허브 레포 세팅 + 마라 앱 이전
2주차   홈 화면 디자인 + 점심 룰렛 앱 제작
3주차   뭐 볼까 앱 + 카카오 공유 붙이기
4주차   도메인 구입 + 첫 번째 SNS 공개
```

### Phase 2 — 콘텐츠 확장 (3~6개월)

#### 앱 로드맵
| 앱 | 검색 키워드 | 바이럴 포인트 |
|---|---|---|
| 👫 데이트 코스 뽑기 | "데이트 어디가지" | 커플이 같이 뽑고 캡처 공유 |
| 💸 누가 낼까? | "더치페이 룰렛" | 회식 후 즉시 사용 |
| 👗 오늘 뭐 입지? | "코디 추천" | 날씨 API 연동 |
| 🏃 오늘의 운동 | "운동 뽑기" | 헬스 루틴 랜덤 |
| ☕ 카페 메뉴 뽑기 | "카페 뭐 마실까" | 스타벅스/이디야 메뉴 |
| 🎮 오늘의 게임 | "게임 뭐 할까" | 스팀/모바일 장르 |

#### SEO 전략
- 각 앱마다 독립 URL + 메타 태그
- "점심 메뉴 추천", "데이트 장소 추천" 등 롱테일 키워드 유입
- 결과 카드 이미지 공유 → 카카오톡/인스타 바이럴
- 카카오 공유 버튼 추가 (현재 Web Share API → 카카오 SDK)
